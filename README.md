# Image Zoom with Lens Effect

A lightweight JavaScript-based image zoom feature using a lens and 
zoom preview box — perfect for product pages or detail views. 
Desktop-friendly and mobile-adaptive (non-touch gestures only).

![Preview](preview.gif)

## ✨ Features

- Mouse-based lens magnifier effect
- Preview zoom box showing magnified section
- Responsive layout (mobile-friendly)
- Simple, dependency-free JS
